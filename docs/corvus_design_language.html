4. "+ Sistem Ekle" Modalı (Sheet.tsx Standartı)

Corvus'un Sheet ve Modal yapısında kullandığı tutamaç çubuğu (handle), koyu zemin ve tek satırlık kopyalanabilir Docker komutu.

Yeni Sistem / Düğüm Ekle
Uç sunucunuzda Corvus Agent'ı başlatın. Dışarıya hiçbir port açmanız gerekmez.
docker run -d --name corvus-agent --restart unless-stopped \
-v /var/run/docker.sock:/var/run/docker.sock \
-e HUB_URL="https://corvus.your-domain.com" \
-e NODE_KEY="crv_live_9f82c81a..." \
ghcr.io/corvus/agent:latest
Bağlantı bekleniyor... Hedef sunucuda komut çalıştığında sistem otomatik tanınacaktır.
